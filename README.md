# sleepy
Sleepy is a programming language designed for being expectable and readable.
It's syntax is made to be understood even if you don't know the language.

## Download
This section will help you install **sleepy**.
### Step 1:
  Go to the releases section (It's on the right side of the screen)
  and download the latest windows binaries.
  *Linux and MacOS systems are not yet supported.*
### Step 2:
  Press the **Windows** key and type **`Edit the system enviroment variables`**
  And press **Enviroment variables...** button.
  Open the program, and double click on **Path**.
  Then, press **Edit** and copy & paste the path to the **sleepy** executable.
  Click **save

When you do these steps, **sleepy** should be installed system-wide for all users.
